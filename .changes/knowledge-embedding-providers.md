titulo: A base de conhecimento pode usar embedding independente do modelo do agente
---

A organização pode configurar SiliconFlow, Alibaba Cloud Bailian ou OpenAI para indexar e consultar materiais, com credencial cifrada e dimensão verificada. Salvar não chama o provedor; a validação é explícita e pode ser cobrada. A troca de modelo exige reindexação, preserva os vetores anteriores e impede misturar espaços vetoriais diferentes. A instalação continua funcionando sem configuração nova.
